Each set in this folder contains log files from a fictional M365 Business Email Compromise incident, created to practice incident investigation and log analysis.

These log file sets were generated based on some of my experiences in responding to and investigating hundreds of BEC incidents. Self-consistency and verisimilitude were striven for throughout, but not perfectly achieved.

These log files are a work of fiction. No identification with actual persons (living or deceased), places, buildings, and products is intended or should be inferred. Any resemblance to actual persons, living or dead, or actual events is purely coincidental.
